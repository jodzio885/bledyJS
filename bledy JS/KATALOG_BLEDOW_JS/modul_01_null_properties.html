Karta Błędu JS #01

Cannot read properties of null

← Powrót do spisu błędów
Komunikat w konsoli (Chrome / Edge / V8):
Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')
Warianty: (reading 'value'), (reading 'innerHTML'), dawniej: Cannot read property '...' of null
1. Opis i przyczyna wystąpienia błędu

Próbujesz odczytać właściwość (np. .value) lub wywołać funkcję (np. .addEventListener()) na obiekcie, który... w ogóle nie istnieje w pamięci – jest równy null.


W 95% przypadków w zadaniach szkolnych i na egzaminie INF.03 oznacza to:

  • Użyłeś document.getElementById(...) lub document.querySelector(...), ale JavaScript nie znalazł takiego elementu na stronie i zwrócił null.
  • Skrypt wykonał się zanim przeglądarka zdążyła wczytać kod HTML.
2. Środowisko testowe: Symulacja błędu w DevTools

Otwórz konsolę deweloperską przeglądarki (F12 lub Ctrl + Shift + I → zakładka Console), a następnie klikaj poniższe przyciski:

PODGLĄD KONSOLI (WIRTUALNA REPLIKA KONSOLI F12) Gotowa
// Kliknij jeden z powyższych przycisków, aby wywołać błąd...
3. Typowe przyczyny wystąpienia błędu (INF.03)

Pułapka 1: Skrypt w sekcji <head> bez atrybutu defer

Gdy skrypt ładuje się w nagłówku strony, przeglądarka wykonuje go zanim odczyta znaczniki w <body>. W chwili wywołania element jeszcze nie powstał!

Pułapka 2: Literówka w nazwie identyfikatora

W pliku HTML masz <button id="przyciskOblicz">, a w JS wpisujesz document.getElementById('przycisk_oblicz') lub getElementById('przyciskoblicz'). Wielkość liter i znaki mają kluczowe znaczenie!

Pułapka 3: Zapomniany hash '#' w querySelector

Pamiętaj: getElementById('btn') pobiera bez hasha, ale querySelector('#btn') musi mieć znak # dla id lub kropkę . dla klasy!

4. Standardowe procedury naprawcze
KOD NIEPOPRAWNY (Wywołuje błąd)
<!-- HTML w sekcji HEAD -->
<script src="skrypt.js"></script>

// skrypt.js
const btn = document.getElementById('przycisk');
// Jeśli nie ma takiego ID, btn to null!
btn.addEventListener('click', () => {
  alert('Kliknięto');
});
KOD POPRAWNY (Rozwiązanie: defer)
<!-- Dodaj atrybut defer -->
<script src="skrypt.js" defer></script>

// lub umieść <script> na samym 
// końcu <body> tuż przed </body>
ROZWIĄZANIE ZALECANE (Guard Clause / Weryfikacja referencji)

Dobra praktyka programistyczna – zanim cokolwiek zrobisz z elementem, sprawdź czy istnieje:

const btn = document.getElementById('przycisk');

if (btn) {
  // Ten kod wykona się TYLKO wtedy, gdy przycisk rzeczywiście istnieje!
  btn.addEventListener('click', () => {
    console.log('Działa!');
  });
} else {
  console.warn('Uwaga: Nie znaleziono przycisku o id "przycisk" w dokumencie HTML!');
}
