Karta Błędu JS #03

Cannot read properties of undefined

← Powrót do spisu błędów
Komunikat w konsoli:
Uncaught TypeError: Cannot read properties of undefined (reading 'miasto')
Warianty: (reading 'length'), (reading 'name'), dawniej: Cannot read property 'x' of undefined
1. Opis i przyczyna wystąpienia błędu

Ten błąd pojawia się, gdy czytasz pole z obiektu lub tablicy po kropce (np. obiekt.pole), ale to, co stoi przed kropką, ma wartość undefined.


Różnica między null a undefined:
• null = zazwyczaj efekt metod DOM (np. przeglądarka szukała elementu HTML, ale go nie znalazła).
• undefined = zmienna istnieje, ale nikt nie przypisał do niej wartości, obiekt nie ma takiego pola, albo wyszedłeś poza rozmiar tablicy!
2. Środowisko testowe: Symulacja błędu w DevTools

Zobacz, co dzieje się przy pracy z obiektami i tablicami:

3. Typowe przyczyny wystąpienia błędu (INF.03)

1. Tablica z indeksowaniem od 1 zamiast od 0

W 3-elementowej tablicy indeksy to 0, 1, 2. Jeśli spróbujesz odczytać klienci[3].imie, klienci[3] da undefined, a odczyt .imie rzuci błąd!

2. Funkcja, która nic nie zwraca (brak return)

Jeśli funkcja nie zawiera instrukcji return, automatycznie zwraca undefined. Przypisanie jej wyniku do zmiennej i czytanie pól z tej zmiennej skończy się błędem.

3. Dane z API / bazy danych, które jeszcze nie dotarły

Próba renderowania profil.dane.email zanim zapytanie asynchroniczne (fetch) skończyło pobierać dane.

4. Standardowe procedury naprawcze (Optional Chaining)
ŹLE (zawiesza skrypt)
const uczen = {
  imie: "Jan"
  // brak pola adres!
};

// uczen.adres to undefined,
// a próba czytania .miasto wywala błąd:
console.log(uczen.adres.miasto);
// TypeError: Cannot read properties of undefined
NOWOCZEŚNIE: Operator ?.
const uczen = {
  imie: "Jan"
};

// Operator ?. (Optional Chaining)
// Jeśli uczen.adres nie istnieje, zwróci undefined
// ZAMIAST rzucać błąd!
console.log(uczen.adres?.miasto); // undefined

// Z wartością domyślną (??):
const miasto = uczen.adres?.miasto ?? "Brak danych";
console.log(miasto); // "Brak danych"
