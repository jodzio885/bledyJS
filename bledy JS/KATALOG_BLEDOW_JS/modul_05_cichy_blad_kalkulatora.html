Błąd Logiczny #05

2 + 2 = "22" (Cichy błąd kalkulatora)

← Powrót do spisu błędów
Objaw na stronie:
Wpisujesz w kalkulatorze 2 oraz 2, a wynik na ekranie to 22 zamiast 4!
Konsola DevTools (F12) NIE pokazuje żadnego błędu, bo dla JavaScriptu operacja jest formalnie poprawna.
1. Opis i przyczyna wystąpienia błędu

Właściwość input.value ZAWSZE zwraca ciąg znaków (String), nawet jeśli w HTML zdefiniowałeś <input type="number">!


Gdy używasz operatora + na napisach:

"2" + "2" = "22"  // JavaScript skleił (skonkatenował) dwa teksty zamiast je dodać!

Co ciekawe: odejmowanie "10" - "2" daje 8 (bo JS automatycznie konwertuje przy minusie), przez co błąd pojawia się tylko przy dodawaniu!

2. Środowisko testowe: Symulacja błędu w DevTools
+
Wynik w programie:
Kliknij jeden z przycisków
3. Standardowe procedury naprawcze
KOD NIEPOPRAWNY (Błąd konwersji)
const a = document.getElementById('l1').value;
const b = document.getElementById('l2').value;

// a i b to stringi np. "5" i "7"!
const wynik = a + b; 
// wynik to "57" (tekst)
KOD POPRAWNY (Konwersja numeryczna)
// Opcja 1: Funkcja Number() - ZALECANA
const a = Number(document.getElementById('l1').value);
const b = Number(document.getElementById('l2').value);
const wynik = a + b; // wynik to 12 (liczba)

// Opcja 2: parseInt (dla całkowitych)
const a = parseInt(document.getElementById('l1').value, 10);

// Opcja 3: parseFloat (dla ułamków)
const a = parseFloat(document.getElementById('l1').value);
