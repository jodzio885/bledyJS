Karta Błędu JS #06

Assignment to constant variable

← Powrót do spisu błędów
Komunikat w konsoli:
Uncaught TypeError: Assignment to constant variable.
Występuje zawsze przy próbie użycia znaku równości = na zmiennej zadeklarowanej przez const.
1. Opis i przyczyna wystąpienia błędu

Słowo kluczowe const tworzy stałą referencję. Oznacza to, że po przypisaniu początkowej wartości NIE MOŻESZ użyć operatora przypisania = ani operatorów inkrementacji ++ czy --.


Najważniejsza pułapka (Mutacja a Re-assignment):
• const liczby = [1, 2]; liczby.push(3); → DZIAŁA! Modyfikujesz zawartość tablicy, ale nie zmieniasz samej referencji do tablicy.
• const liczby = [1, 2]; liczby = [1, 2, 3]; → BŁĄD! Znak = to próba ponownego przypisania.

3. Reguły deklaracji: Wybór let lub const
KOD NIEPOPRAWNY: Licznik zadeklarowany jako const
// Licznik kliknięć będzie się zmieniał:
const klikniecia = 0;

button.addEventListener('click', () => {
  // BŁĄD! TypeError
  klikniecia++; 
});
KOD POPRAWNY: Zastosowanie deklaracji 'let'
// Jeśli wartość ma się zmieniać, użyj let:
let klikniecia = 0;

button.addEventListener('click', () => {
  klikniecia++; // Działa perfekcyjnie!
  console.log('Kliknięto:', klikniecia);
});
