Karta Błędu JS #07

SyntaxError: Unexpected token

← Powrót do spisu błędów
Komunikat w konsoli:
Uncaught SyntaxError: Unexpected token ')'
Warianty: Unexpected end of input, Unexpected token < in JSON at position 0
1. Opis i przyczyna wystąpienia błędu

Ten błąd różni się od pozostałych tym, że powstaje zanim jakakolwiek linijka kodu zostanie w ogóle wykonana. Silnik JS czyta plik tekstowy, napotyka znak niezgodny z gramatyką języka i natychmiast przerywa działanie całego skryptu.


Najczęstsze przyczyny:

  • Niedomknięty nawias ), klamra } lub cudzysłów.
  • Komunikat Unexpected end of input oznacza: skrypt nagle się skończył, a silnik wciąż czekał na zamknięcie otwartej klamry }!
  • Błędny format danych przy JSON.parse().

3. Typowe przyczyny wystąpienia błędu (INF.03)

Format JSON jest znacznie bardziej rygorystyczny niż zwykły obiekt w pliku JS:

BŁĘDNY FORMAT DANYCH JSON
// 1. Klucze bez podwójnych cudzysłowów
{ imie: "Jan" }

// 2. Pojedynczy cudzysłów
{ 'imie': 'Jan' }

// 3. Przecinek na końcu (trailing comma)
{ "imie": "Jan", "wiek": 18, }
POPRAWNY FORMAT DANYCH JSON
// Klucze i teksty MUSZĄ mieć "podwójne" cudzysłowy!
// Brak przecinka po ostatnim polu!
{
  "imie": "Jan",
  "wiek": 18
}
