Karta Błędu JS #04

... is not defined

← Powrót do spisu błędów
Komunikat w konsoli:
Uncaught ReferenceError: wynik is not defined
Pokrewny błąd: Cannot access 'wynik' before initialization (użycie przed let/const)
1. Opis i przyczyna wystąpienia błędu

Próbujesz odczytać zmienną, której silnik JavaScript nie może znaleźć w bieżącym zasięgu (scope).


Dwa główne powody:

  • Zmienna jest uwięziona wewnątrz innej funkcji: Jeśli stworzysz let wynik = 10; wewnątrz funkcji policz(), to na zewnątrz ta zmienna przestaje istnieć.
  • Literówka w nazwie zmiennej: Zadeklarowałeś let cenaRazem = 100;, a w dalszej części kodu odwołujesz się do cena_razem lub cenarazem.

3. Typowe przyczyny wystąpienia błędu (INF.03)

Częsty błąd ucznia: obliczenia wykonane w jednej funkcji, a wyświetlenie wyniku w drugiej bez zwrócenia wartości (return):

KOD NIEPOPRAWNY (Błąd zasięgu)
function obliczPole() {
  const bok = 5;
  const pole = bok * bok; // zmienna lokalna!
}

function wyswietl() {
  obliczPole();
  // BŁĄD: pole nie istnieje w tej funkcji!
  console.log('Pole wynosi:', pole); 
  // ReferenceError: pole is not defined
}
KOD POPRAWNY (Zwracanie przez return)
function obliczPole() {
  const bok = 5;
  return bok * bok; // zwracamy wynik!
}

function wyswietl() {
  // odbieramy zwróconą wartość do zmiennej:
  const pole = obliczPole(); 
  console.log('Pole wynosi:', pole); // Działa!
}
