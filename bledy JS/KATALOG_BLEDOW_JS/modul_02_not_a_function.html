Karta Błędu JS #02

... is not a function

← Powrót do spisu błędów
Komunikat w konsoli:
Uncaught TypeError: btn.addEventlistener is not a function
Warianty: tekst.toLowercase is not a function, oblicz(...) is not a function
1. Opis i przyczyna wystąpienia błędu

Dopisałeś nawiasy wywołania () do czegoś, co dla JavaScriptu nie jest funkcją.


Najczęstsze scenariusze:

  • Literówka w wielkości liter (CamelCase): JS odróżnia małe i wielkie litery. Na przykład addEventlistener to nie to samo co addEventListener (małe 'l' zamiast wielkiego 'L').
  • Zmienna nadpisała funkcję: Zdefiniowałeś funkcję oblicz(), ale potem stworzyłeś zmienną o tej samej nazwie: let oblicz = 10; i próbujesz wywołać oblicz().
  • Zły typ danych: Próbujesz wywołać metodę tablicową na liczbie lub tekście (np. (123).push()).

3. Typowe przyczyny wystąpienia błędu (INF.03)

4. Standardowe procedury naprawcze
PRZYKŁAD 1 (Błędny): Wywołanie pola jak funkcji
const poleTekstowe = document.getElementById('imie');

// BŁĄD: .value to tekst, a nie funkcja!
const imie = poleTekstowe.value(); 
// TypeError: poleTekstowe.value is not a function
POPRAWKA 1: Usunięcie nawiasów ()
const poleTekstowe = document.getElementById('imie');

// POPRAWNIE: odczytujemy właściwość
const imie = poleTekstowe.value;
console.log('Wpisano:', imie);
PRZYKŁAD 2 (Błędny): Konflikt nazw zmiennych
function oblicz(a, b) {
  return a + b;
}

// Nadpisanie funkcji zmienną o tej samej nazwie!
let oblicz = 50;

// Próba wywołania liczby 50 jako funkcji:
oblicz(5, 10); // TypeError: oblicz is not a function
POPRAWKA 2: Rozdzielenie przestrzeni nazw
function oblicz(a, b) {
  return a + b;
}

// Zmienna z wynikiem ma unikalną nazwę:
let wynikObliczen = oblicz(5, 10);
console.log('Wynik:', wynikObliczen);
